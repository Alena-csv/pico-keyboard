# Pico Virtual Keyboard

Экранная клавиатура для Windows на стандартной библиотеке Python (`tkinter` + WinAPI), без сторонних зависимостей.

## Возможности
- Тёмно-синяя тема с крупным жирным шрифтом.
- Окно поверх всех окон и не забирает фокус — текст печатается туда, где стоит курсор.
- Русская и английская раскладки (`RU`/`EN`), не зависит от системной раскладки Windows.
- Залипающие модификаторы (`Shift`, `Ctrl`, `Alt`, `Win`): 1 клик — разово, 2 клика — закрепить, 3 — выключить.
- Масштабирование окна за правый нижний уголок (двойной клик по уголку — сброс на `100%`, масштаб запоминается).
- Буфер обмена: быстрые кнопки `Копировать` / `Вырезать` / `Вставить` / `Выделить всё` / `↶` и история скопированных записей с закреплением (`📌`).

## Запуск
- Двойной клик по `start_hidden.vbs` (нужен Python 3 с `tcl/tk`).
- Автозапуск при входе в Windows: `install_autostart.bat` (отключить — `remove_autostart.bat`).

## Настройки
Все параметры темы, размеров клавиш, шрифтов и буфера обмена задаются в `config.json`:
- `цвета` — палитра тёмно-синей темы;
- `размеры` — размеры клавиш, `размер_шрифта`, `размер_шрифта_буфера`, `жирный_шрифт`;
- `клавиатура` — `раскладка_при_запуске` (`ru`/`en`), `прозрачность` (`0.3–1.0`);
- `буфер_обмена` — `размер_истории`, `показывать_историю_при_запуске`.
