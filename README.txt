Pico Virtual Keyboard

ЗАПУСК
  Двойной клик по start_hidden.vbs (нужен Python 3 с галочкой "tcl/tk", по умолчанию она стоит).
  Сторонние библиотеки не нужны: pyautogui и браузер больше не используются.

ПО УМОЛЧАНИЮ (автозапуск)
  install_autostart.bat — клавиатура будет открываться при входе в Windows.
  remove_autostart.bat  — убрать из автозапуска.
  Если папку перенесёте — запустите install_autostart.bat ещё раз.

КАК ПОЛЬЗОВАТЬСЯ
  • Окно не забирает фокус: кликните в нужную программу и печатайте мышкой.
  • Перетаскивать — за полоску «⠿ Pico Keyboard». Положение запоминается.
  • Изменить размер — потяните за уголок внизу справа (двойной клик по уголку — сброс 100%).
  • RU/EN — смена раскладки (не зависит от раскладки Windows).
  • Shift / Ctrl / Alt: 1 клик — на одну клавишу, 2 клика — закрепить, 3 — выключить.
    Например: Ctrl → C = копировать, Ctrl+Shift → стрелки = выделение.
  • Win: 1 клик + клавиша = сочетание (Win → D), 2 клика = меню Пуск.
  • Backspace, буквы и стрелки повторяются, если удерживать.
  • «—» сворачивает в полоску, «✕» закрывает.

БУФЕР ОБМЕНА
  • Копировать / Вырезать / Вставить / Выделить всё / ↶ (отменить) — для текущей программы.
  • «История» — список последних скопированных текстов (из любой программы).
    Клик — вставить, «📌» — закрепить сверху, правый клик — удалить, «Очистить» — стереть незакреплённые.
  • Обычная история стирается при закрытии, а закреплённые записи (📌) сохраняются между запусками.

НАСТРОЙКИ — config.json
  цвета, размеры кнопок, размер_шрифта, размер_шрифта_буфера, жирный_шрифт (true/false),
  раскладка_при_запуске (ru/en), прозрачность (0.3–1.0),
  размер_истории, показывать_историю_при_запуске (true/false).

ОГРАНИЧЕНИЕ
  В программы, запущенные «от имени администратора», Windows не даёт печатать
  обычным программам. Если нужно и туда — запускайте клавиатуру тоже от администратора.
